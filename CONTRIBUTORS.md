## How to Add Collaborators

1. Go to your repository on GitHub
2. Click **Settings** → **Collaborators**
3. Click **Add people**
4. Enter the GitHub username or email
5. Select the permission level:
   - **Read** — can view and clone
   - **Triage** — can manage issues and pull requests
   - **Write** — can push to branches
   - **Maintain** — can manage workflows
   - **Admin** — full access

## Contributing Guidelines

- Follow the existing code style and structure
- Test changes locally with `npm run dev`
- Run `npm run build` before pushing to ensure no build errors
- Keep commits descriptive and focused
